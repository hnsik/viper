# Viper Royale — Snake Arena

Student project: a slither.io-style snake game in a single `index.html` (HTML5 canvas, no dependencies).

- Steer with the mouse / touch drag, or A/D and arrow keys
- Hold left mouse button / Space / W (or the ⚡ button on mobile) to boost
- Eat orbs to grow, make bots crash into each other and collect the coins they drop
- Sound is synthesized with the Web Audio API (🔊 button to mute)

Open `index.html` in a browser to play.
